# 赛段二 Isaac 真值接口合规核查

核查日期：2026-07-31

## 结论

当前不能把 `/drone0/state/pose` 标记为“已确认合规”。仓内两份官方材料要求同一仿真
世界连续运行、无人机自主起飞避障、机载视觉动态识别与对准、禁止人工编码标签，并要求
提交真实可复现的工程和日志；材料中没有明文禁止 Isaac/Pegasus 原始状态，也没有明文
授权把场景真值用于飞行闭环。因此该项状态是 **待书面确认**，不是通过。

在得到主办方明确答复前，正式视频与技术文档不得把当前链路描述成“纯 PX4 估计闭环”。

## 当前使用范围

| 使用点 | 作用 | 是否直接写 PX4 setpoint |
|---|---|---|
| 解锁前姿态/静止一致性门控 | 防止飞机倾斜或滑出托架后解锁 | 否 |
| 起飞导轨脱离见证 | 决定何时从垂直模式切到完整水平控制 | 间接影响控制模式 |
| 返航最后 0.45 m 低速校正 | 对准 10 mm 间隙的起飞托架 | 是，通过唯一 executor 转成 PX4 意图 |
| rosbag/验收统计 | 速度、落点及仿真误差证据 | 否 |

航路规划、EGO 障碍检测和常规轨迹跟踪使用 PX4 估计里程计；但最后两项闭环依赖意味着
当前实现仍不是纯估计/机载传感器闭环。

## 官方材料对应条款

- `docs/competition/第二十五届全国大学生机器人大赛ROBOTAC AIROBOTIC赛项 预选赛评审细则-0626.docx`
  要求同一仿真世界连续运行、自主起飞避开主要障碍、机载视觉动态识别对准、返航或安全
  降落，并禁止二维码、AprilTag 等人工编码标签。
- `docs/competition/预选赛作品提交规则(1).docx` 要求完整连续视频、不得剪辑拼接或中途
  重置，并提交传感器参数及完整工程。
- 两份材料均未定义“允许用于控制的 Isaac topic 白名单”，也未说明
  `/drone0/state/pose` 是否属于规则允许的控制输入。

## 关闭条件

二选一完成后才可关闭：

1. 获得主办方/裁判委员会对 `/drone0/state/pose` 上述三个在线用途的书面允许，并把答复
   随工程归档；或
2. 正式比赛配置移除在线真值依赖：导轨脱离使用 PX4 高度/测距，近场返航使用下视自然
   视觉或合规测距；真值 topic 只保留为不影响控制的录包评估量。

现阶段建议先询问主办方，同时保留“安全降落到宽阔区域”的无真值备选方案；评审细则只
要求返航或安全降落，并未要求重新插入毫米级起飞托架。
